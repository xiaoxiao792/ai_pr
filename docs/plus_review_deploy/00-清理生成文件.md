# 清理生成文件

这份只讲怎么清理，不讲部署。

## 推荐清理方式

先进入仓库：

```bash
cd /opt/PR-Agent
```

先预览会删除什么：

```bash
git clean -ndX
```

确认里面只有这些东西再继续：

```text
__pycache__/
.pytest_cache/
.ruff_cache/
.mypy_cache/
*.pyc
*.pyo
plus_review_*.log
build/
dist/
*.egg-info/
```

执行清理：

```bash
git clean -fdX
```

## 不要删

不要手动删这些：

```text
.git/
pr_agent/
tests/
requirements.txt
pyproject.toml
```

## 如果你只想删 plus_review 日志

```bash
rm -f plus_review_*.log
```
